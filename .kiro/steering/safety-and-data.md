# Safety and data steering — Underwater Rescue MVP

## Safety language

- Use “suspected victim” or “suspected target” unless a human operator confirms the target.
- Use “oxygen resource simulation” rather than “oxygen delivery.”
- Use “simulation result” rather than “field performance.”
- Never claim medical detection, rescue readiness, or real-world safety from the MVP.

## Data handling

- Never place confidential source images, sonar data, robot parameters, or mission locations in the public repository.
- Store only synthetic data, permitted derived artifacts, or public dataset metadata and download instructions.
- Record source URL, version, license, citation, and allowed use for every public dataset.
- Keep dataset-specific licenses visible in the repository.
