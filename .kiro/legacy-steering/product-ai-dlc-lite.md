# Product: AI-DLC Lite

AI-DLC Lite (AI-Driven Development Life Cycle — Lite) is a streamlined configuration of the full AI-DLC framework, designed for prototypes, demos, and simple projects.

## Purpose

A structured, adaptive software development workflow that guides an AI assistant through the full lifecycle of building software — from requirements gathering to code generation and testing — while maintaining correctness, traceability, and user control.

## Core Philosophy

- **Get to working code faster** without sacrificing correctness
- **Ask fewer questions, but the right ones** — prefer reasonable defaults for low-impact decisions
- **One approval gate** per stage (vs. two in the full version)
- **Bounded follow-up** — max one round of clarifying questions, then proceed with documented assumptions

## Three-Phase Lifecycle

1. **INCEPTION** — Determines WHAT to build and WHY (requirements, design, planning)
2. **CONSTRUCTION** — Determines HOW to build it (code generation, build, test)
3. **OPERATIONS** — Placeholder for future deployment and monitoring workflows

## Key Differentiators from Full AI-DLC

- 51% fewer total lines across rule files
- No mandatory unlimited follow-up question loops
- No separate clarification files (inline instead)
- Collapsed two-part stages (plan + generate) into single flows with one approval gate
- Targeted question categories (2–5 per stage vs. 5–8 in full version)
